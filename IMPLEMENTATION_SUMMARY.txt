HOW TO GET STARTED
================================================================================

STEP 1: Add MongoDB Connection
  1. Go to v0 project settings (top right)
  2. Click "Vars" tab
  3. Add environment variable:
     Key: MONGODB_URI
     Value: mongodb+srv://user:password@cluster.mongodb.net/?retryWrites=true
  4. Save and restart dev server

STEP 2: Verify Connection
  Run: node --env-file-if-exists=/vercel/share/.env.project scripts/verify-db.js
  Should show: ✅ Connection successful!

STEP 3: Test the System
  1. Add a car in /admin
  2. Go to car detail page
  3. Fill booking form
  4. Submit
  5. WhatsApp opens
  6. Check /admin/bookings to see saved booking

STEP 4: Deploy
  Push to main branch - all components ready!

DATABASE SCHEMA
================================================================================

BOOKINGS COLLECTION:
  _id: ObjectId (auto-generated)
  carId: string
  carDetails: {
    make: string
    model: string
    year: number
    price: number
  }
  customerName: string
  customerEmail: string
  customerPhone: string
  bookingType: "inquiry" | "test-drive" | "inspection" | "delivery-quote"
  message: string
  status: "pending" | "confirmed" | "completed" | "cancelled"
  sentViaWhatsApp: boolean
  createdAt: Date
  updatedAt: Date

INDEXES:
  • createdAt (desc) - for sorting
  • carId (asc) - for car filtering
  • customerEmail (asc) - for finding customer
  • status (asc) - for status filtering

   Q: "MONGODB_URI not set"
   A: Add MONGODB_URI to environment variables in project settings

   Q: "Connection rejected"
   A: Check MongoDB credentials, make sure IP is whitelisted

   Q: "WhatsApp not opening"
   A: Check browser security settings, allow pop-ups

   Q: "Booking not saving"
   A: Check network tab in F12, verify API response
